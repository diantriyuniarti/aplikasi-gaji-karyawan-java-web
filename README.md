---

## 🌟 Fitur Utama

- **👥 Manajemen Data Karyawan**:
  - Input NIK, nama lengkap, jabatan, golongan, status pernikahan, dan jumlah tanggungan.
- **💵 Perhitungan Gaji Otomatis**:
  - Kalkulasi gaji pokok, tunjangan jabatan, tunjangan keluarga, uang makan, potongan BPJS, dan PPh 21.
- **🖨️ Cetak Slip Gaji & Rekapitulasi (JasperReports / iReport)**:
  - Export laporan format PDF siap cetak dengan layout profesional (`reports/slip_gaji.jrxml`).
- **🗄️ Koneksi MySQL JDBC**:
  - Menggunakan driver `mysql-connector-j-8.0.31.jar` untuk transaksi basis data relasional.

---

## 🚀 Panduan Menjalankan

1. Buka **NetBeans IDE**.
2. Pastikan server lokal GlassFish / Apache Tomcat sudah terpasang.
3. Buka proyek `aplikasi-gaji-karyawan-java-web`.
4. Jalankan XAMPP MySQL.
5. Klik **Run** pada proyek untuk menjalankan di browser lokal.
